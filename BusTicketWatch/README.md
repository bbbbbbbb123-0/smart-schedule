# Билеты Индер — Атырау (Android)

Приложение для проверки мест на рейс Индер → Атырау, 26.10.2026 в 17:00.

- Открывает актуальную страницу сайта через Android WebView.
- Выбирает строку отправления 17:00 и читает схему мест из текущей страницы.
- Свободными считаются только места со статусом status-0; занято (status-1) и бронь (status-4) свободными местами не считаются.
- При подтверждённых свободных местах отправляется уведомление Android.
- Проверка запрашивается примерно раз в час; Android может задерживать её в режиме энергосбережения.
- Мониторинг прекращается после времени отправления.
